# Fonts for the panel tools

Montserrat Bold and Light, used by `tools/gen_title_paths.py` and
`tools/gen_panel.py` to turn panel text into SVG paths. From
<https://github.com/JulietaUla/Montserrat>, licensed under the SIL Open Font
License 1.1 (`OFL.txt`), separately from pages64's GPL. The fonts are a build
tool only: they are not part of the plugin package, whose panels carry the
text as paths.
